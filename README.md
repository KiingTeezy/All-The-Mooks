# All-The-Mooks

Modpack distribution for **All The Mooks** — `mooksvill.datho.st`

**Current: All the Mods 11 0.8.0-beta** · Minecraft 26.1.2 · NeoForge 26.1.2.106

## Install

1. Install [Prism Launcher](https://prismlauncher.org)
2. **Add Instance** → **Import**
3. Paste the `.mrpack` link from the [latest release](https://github.com/KiingTeezy/All-The-Mooks/releases/latest)
4. Launch and join `mooksvill.datho.st`

ATM10 instances cannot be updated to ATM11 — Minecraft 1.21.1 and 26.1.2 are not compatible. Import fresh.
