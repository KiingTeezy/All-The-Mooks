# All The Better Mooks

Modpack for the **All The Mooks** server - `mooksvill.datho.st`

**Current: All The Better Mooks v3.0.0** - ATM11 0.8.0-beta + BMC6 exploration layer - Minecraft 26.1.2 - NeoForge 26.1.2.109

## Install

1. Install [Prism Launcher](https://prismlauncher.org)
2. **Add Instance** -> **Import**
3. Paste the `.mrpack` link from the [latest release](https://github.com/KiingTeezy/All-The-Mooks/releases/latest)
4. Right-click the instance -> **Edit** -> **Settings** -> **Memory** -> set maximum to **10240 MB**
5. Launch and join `mooksvill.datho.st`

Each major version is a fresh import - older instances cannot be updated across them.
